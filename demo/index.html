কীভাবে কাজ করে / How it works: 25 ms Hamming-windowed frames (10 ms hop) are extracted locally. Each voiced frame gets a fundamental-frequency estimate by autocorrelation (search 75–500 Hz); jitter = mean relative period perturbation between consecutive voiced frames; shimmer = mean relative peak-amplitude perturbation; pause ratio = unvoiced-frame share over the last ~8 s window. The composite “prosody strain” index is an exploratory heuristic mapped from these features — the same pipeline ships inside the PRISM edge agent (Python reference implementation in core_engine/acoustic_biomarker.py, validated by unit tests).
